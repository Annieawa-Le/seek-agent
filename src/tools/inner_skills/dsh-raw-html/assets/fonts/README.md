# 内置字体 · 来源与许可

本目录的 `*.woff2` 是视觉卡片可用的内置字体。为与上游 DSH 的 `Lanxi-*`
字体族命名保持一致，文件被统一加了 `Lanxi-` 前缀；**文件内容即各自的原始
开源字体**（版权与许可信息来自各字体内嵌的 `name` 表）。

## 许可

全部保留字体均以 **SIL Open Font License 1.1** 分发，全文见
[`LICENSE-OFL-1.1.txt`](LICENSE-OFL-1.1.txt)。
